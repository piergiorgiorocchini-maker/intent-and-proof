# Intent & Proof

Astro website for [www.intentandproof.com](https://www.intentandproof.com).

Intent & Proof builds measurable customer acquisition systems for service businesses through strategy, search, high-converting websites, proof, tracking and automation.

## Commands

| Command | Action |
| :-- | :-- |
| `npm install` | Install dependencies |
| `npm run dev` | Start the local development server |
| `npm run build` | Build the production site |
| `npm run preview` | Preview the production build locally |
